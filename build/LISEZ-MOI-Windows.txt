INSTALLATION
============

1. Extraire ce fichier ZIP dans un dossier de votre choix
   (ex: C:\Program Files\BilletteraPrintAgent)

2. Double-cliquer sur BilletteraPrintAgent.exe

3. IMPORTANT - Premier lancement :
   Windows affichera "Windows a protégé votre ordinateur"

   → Cliquer sur "Informations complémentaires"
   → Cliquer sur "Exécuter quand même"

   Cet avertissement n'apparaîtra qu'une seule fois.

4. Une icône "Billettera" apparaît dans la barre des tâches
   (près de l'horloge)


UTILISATION
===========

- L'agent fonctionne en arrière-plan
- Il écoute les commandes de billettera.com sur le port 19195
- Pour quitter : clic droit sur l'icône → "Quitter"


DÉMARRAGE AUTOMATIQUE (optionnel)
=================================

Pour lancer l'agent automatiquement au démarrage de Windows :

1. Appuyer sur Win + R
2. Taper : shell:startup
3. Copier un raccourci de BilletteraPrintAgent.exe dans ce dossier


CONFIGURATION (optionnel)
=========================

Créer un fichier "config.json" à côté de l'exécutable :

{
    "port": 19195,
    "allowed_origins": ["https://billettera.com"],
    "default_printer": "EPSON TM-T20III"
}
